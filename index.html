IoT landing page

Bifrost

An intelligent communication hub that connects and manages devices using different wireless technologies, seamlessly and efficiently.

Sensors that speak different "languages" (ESP-NOW, LoRa, MQTT) send their messages to gateways, and a Raspberry Pi decides where each message goes, translating between protocols.

Robotics, at SETREM

Atlas

The robot of the Computer Engineering course at SETREM: it drives, finds its position, talks and shows its data in an app.

It is split in three parts: the body (motors, GPS, Wi-Fi and telemetry on a Raspberry Pi), the face (an animated face with voice and AI chat) and the controller (a Flutter app that drives it over Bluetooth).

  • Python
  • Flutter
  • Raspberry Pi
  • Bluetooth LE

Industrial automation, at Tecnicon

Asimov

A collector that reads data from industrial machines (PLCs and HMIs) over the network and sends it to the server. It works with WEG, Siemens, Rockwell, Mitsubishi, Omron and any Modbus, OPC UA or MQTT device.

It only reads and never writes to the PLC, so it is safe for machines in production. Data waits in a queue until it reaches the server, so nothing is lost if the network drops.

  • Python
  • Modbus
  • OPC UA
  • Redis

Game

Câmara 7

A 2D mining and horror game set in a fictional mine near Chernobyl, April 1986. You play a Shift C miner and slowly uncover what lies behind Chamber 7.

Built in Godot in pixel art, with a Windows installer and automatic updates: the game downloads only the new content (about 4 MB), checks its integrity and never touches your saves.

  • Godot
  • GDScript
  • Pixel art
